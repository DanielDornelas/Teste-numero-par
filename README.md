# Jogo Par ou Ímpar

Um programa simples em Python que diz se o número digitado é par ou ímpar.

## Como funciona

O programa pede para você digitar um número e responde se ele é **par** ou **ímpar**. Ele continua pedindo números até você encerrar.

## Como executar

1. Tenha o [Python](https://www.python.org/downloads/) instalado.
2. Clone o repositório:
```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
```
3. Entre na pasta e rode:
```bash
   python main.py
```

Para sair, aperte `Ctrl + C`.
